# Wikist 1.0.4 发布说明

发布日期：2026-08-29
升级来源：Wikist 1.0.x
数据库迁移上限：`0022_open_organization_community`
核心前端资源：`wikist-core-20260829-217`

Wikist 1.0.4 是面向生产可用性、英文界面完整度和搜索发现能力的维护版本。现有站点可以原地升级，不需要重新安装，也不会覆盖站点配置、SQLite 数据库、词条、修订、上传或本地插件缓存。

## 主要更新

- **英文界面**：主站、账户、后台、问答、安装器和划词工具的固定界面文字提供完整内置英文版本；词条、问答、回答、评论、组织资料和其他用户内容不被自动翻译或改写。
- **注册与邮件**：注册表单即时显示用户名和邮箱是否已被占用；后台可发送 SMTP 测试邮件到当前管理员邮箱，并提供可操作的邮件服务错误提示。
- **生产运行**：安装与生产修复工具处理 systemd 环境文件、Centrifugo 运行目录和服务账号权限，生产诊断可识别 TLS 证书未覆盖公开域名的问题。
- **实时 Sitemap**：Sitemap 每次请求读取当前公开内容。导入、创建、更新、恢复或删除内容后，新的 XML 不再等待目录快照或代理缓存过期。
- **品牌搜索**：首页输出规范链接、站点名和品牌别名结构化数据，并用可抓取的公开链接连接知识库、站内问答和协作社区。后台“站点设置”可填写额外品牌别名，例如 `MathSX, mathsx`。
- **协作社区布局**：组织卡片与组织主页的简介横跨可用内容宽度，避免在宽屏下被身份区或基本信息栏提前压窄而过早换行。

## 升级

升级前建议完成一次全站备份，然后执行：

```bash
npm run update -- --preflight-only --yes
npm run update -- --strategy=git --remote=origin --branch=main --service=wikist --yes
```

升级后确认：

```bash
npm run doctor
npm run check
npm run restart
npm run status
```

若站点通过 CDN 提供前端资源，请在升级后清理 CDN 缓存或确保其尊重版本化资源 URL。对于搜索收录，在后台确认公开地址与品牌别名后，将 `/sitemap.xml` 提交到搜索引擎站长平台；XML 会立刻更新，但搜索引擎抓取和结果更新仍由其自身调度决定。
